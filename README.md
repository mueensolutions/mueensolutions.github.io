# Muhammad Mueen — Professional Portfolio

A responsive portfolio website for data entry, online Quran teaching, and Arabic/Persian translation. It includes CSS-based interactive 3D-style concept demonstrations.

## Website files
- `index.html` — page content
- `style.css` — design, layout, responsive styling, and 3D effects
- `script.js` — small JavaScript enhancement

## Before publishing
Replace `[Add your email address]`, `[Add your phone number]`, and `your-email@example.com` in `index.html` with your real contact details. The 3D showcase is labelled as concept demonstrations, not client work.

## Publish with GitHub Pages
Create a public repository named `YOUR-GITHUB-USERNAME.github.io`, upload all three website files to the repository's top level, then open Settings → Pages. Under Build and deployment, choose Deploy from a branch, select `main` and `/(root)`, and save. The website address will be `https://YOUR-GITHUB-USERNAME.github.io/` after deployment.

Official guide: https://docs.github.com/en/pages/quickstart
