# Muhammad Mueen — Professional Portfolio

Service-focused portfolio with CSS 3D illustrations for:
- Data entry (3D data dashboard)
- Online Quran teaching with Tajweed (3D Quran book and rehal)
- Arabic translation (layered multilingual documents)
- Persian translation (3D language globe)

Includes scroll reveal animations, a scroll progress bar, responsive mobile navigation, and reduced-motion accessibility support.

## Upload these files to the root of your GitHub repository
- `index.html`
- `style.css`
- `script.js`

## Before publishing
In `index.html`, replace `[ADD YOUR EMAIL ADDRESS]`, `[ADD YOUR PHONE NUMBER]`, and `your-email@example.com` with your real contact details. Do not publish your CNIC or other sensitive information.

## Publish
Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
